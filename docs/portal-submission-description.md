## Week 2 Portal Submission Description

This Week 2 assessment presents a Master Data Management and Inventory Optimization analysis in SAP SCM. The project connects data quality with planning performance by examining the master-data elements required for reliable supply-chain planning, including material and location information, planning parameters, mappings, units, lead times, and inventory-control settings.

The report explains a practical project approach covering data analysis, cleansing, mapping, validation, configuration guidance, inventory-optimization methods, and post-change monitoring. It also uses simulated stock-out and excess-inventory situations to show how incorrect or poorly governed parameters can affect supply reliability and working capital. Supporting documents provide a data-mapping strategy, inventory-optimization analysis, master-data project plan, risk and validation controls, and editable lifecycle/optimization diagrams.

The assessment emphasizes that master data should be treated as a governed planning input rather than a one-time setup activity. Before applying any parameter change in a live environment, the relevant material-location combinations, units of measure, lead times, safety-stock logic, lot-size rules, and source mappings should be validated and approved.

All scenario values and optimization effects in the report are illustrative learning assumptions. The repository does not claim that the simulated data was extracted from a live SAP system or that the proposed configuration was executed in production. The purpose is to demonstrate structured SAP SCM reasoning, documentation, validation, and inventory decision-making.
